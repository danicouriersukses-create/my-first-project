## 🛠️ Setup Instructions

### Prerequisites
- Groq API Account (free)
- Any modern browser

### Step 1: Get Groq API Key

1. Visit https://console.groq.com
2. Sign up with your email
3. Create an API key
4. Copy the key

### Step 2: Add API Key to App

1. Open `script.js`
2. Find this line:
   ```javascript
   const GROQ_API_KEY = 'YOUR_GROQ_API_KEY_HERE';
   ```
3. Replace with your actual API key:
   ```javascript
   const GROQ_API_KEY = 'gsk_xxxxxxxxxxxxx';
   ```
4. Save the file

### Step 3: Open the App

1. Open `index.html` in your browser
2. Or deploy to GitHub Pages (see below)

## 🚀 Deploy to GitHub Pages

1. Push all files to your GitHub repo
2. Go to Settings > Pages
3. Select `main` branch (or `feature/ai-content-generator`)
4. Select folder: `/ai-content-generator`
5. Click Save
6. Your app will be live at: `https://yourusername.github.io/my-first-project/ai-content-generator/`

## 🐛 Troubleshooting

### "API Error: 401"
- Your API key is invalid or missing
- Check if it's properly added in `script.js`

### "Failed to generate content"
- Check internet connection
- Verify API key has credits
- Try again in a few seconds

### CORS Error
- This app works best when deployed
- Local testing may have CORS issues
